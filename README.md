학교 디지털 시민성 수업에서 쓰는 웹 자료 모음입니다.

| 주소 | 쓰는 사람 | 하는 일 |
|---|---|---|
| `/` | 모두 | 자료를 고르는 첫 화면 |
| `/citizen.html` | 학생 | 수업 코드로 모둠 참여 → 4개 미션 → 결과 브리핑 |
| `/citizen-teacher.html` | 선생님 | 수업 코드 열기, 모둠 순위 실시간 확인, 학생 화면 함께 보기 |
| `/forensics.html` | 학생 | 디지털 감식반 통합 과정 (로그인 없이 혼자 진행) |
| `/virtual.html` | 학생 | 가상 공간 감식반 (단독 과정) |

## 디지털 시민 브리핑

중학교 1~2학년, **2명이 한 모둠**이 되어 하는 짝 활동입니다. Common Sense
Education 디지털 시민성 **중학생 차시** 네 개를 옮겼습니다.

| 미션 | 차시 | 문항 | 다루는 것 |
|---|---|---|---|
| 1 · 내가 공유하는 것 | 7프-01 | 8 | 쿠키, 개인정보 처리방침, 이용 약관, 옵트아웃 |
| 2 · 디지털 평판 | 7정-03 | 8 | 셰어런팅, 태그, 게시 전 체크리스트 |
| 3 · 혐오 표현 대응 | 7폭-02 | 8 | 혐오 표현의 정의, 딜레마, 적극적 행동가 |
| 4 · 가짜와 사기 | 7뉴-02 | 8 | 허위조작정보와 오정보, 수평적 읽기 |

- 각 미션 8문항 중 **4문항에는 ‘추가 판단’**이 따라붙습니다. 판단만이 아니라
  그 근거까지 고르게 해서, 답이 하나로 떨어지지 않는 문제를 다룹니다.
- 문항 1점 + 추가 판단 1점으로, **모둠 만점은 48점**입니다.
- 문항 번호가 짝수면 1번 학생, 홀수면 2번 학생 차례입니다. 미션을 오가도
  담당이 바뀌지 않습니다.
- 화면 위의 **미션 탭(01·02·03·04)을 누르면 그 미션으로 바로 갑니다.** 이미
  답한 문항은 답과 해설이 그대로 보이고, 점수가 다시 오르지는 않습니다.

## 함께 보기 (수업 중 화면 맞추기)

선생님 화면에서 미션을 하나 누르면 **모든 모둠의 화면이 그 미션으로 넘어가고,
학생은 다른 미션으로 가지 못합니다.** 설명하거나 함께 토의할 때 앞서 나가는
것을 막기 위한 것입니다.

오가는 것은 **미션 이름 하나뿐**입니다. 점수는 오가지 않고, 학생은 남의 모둠
점수를 볼 수 없습니다.

`자유롭게`를 누르면 풀립니다. 끄는 것을 잊어도 세 시간이 지나면 저절로
풀립니다.

## 파일

- `index.html` — 자료를 고르는 첫 화면
- `citizen.html` — 학생 화면 (모둠 참여 + 4개 미션 + 결과)
- `citizen-teacher.html` — 선생님 화면 (수업 열기 + 순위표 + 함께 보기)
- `forensics.html` — 디지털 감식반 통합 과정 (혼자 도는 한 장짜리 페이지)
- `virtual.html` — 가상 공간 감식반 (통합 과정의 PART 2 를 따로 쓰는 판)
- `virtual-lesson.html` — 가상 공간 감식반 지도안
- `virtual-worksheet.html` — 가상 공간 감식반 활동지

활동지는 한 파일이고 주소로 판이 갈린다. 그냥 열면 학생용이라 교사용
답안 구간이 나오지 않고, `?teacher` 를 붙이면 답안이 함께 보인다.
첫 화면은 학생용 주소로, 선생님 화면은 `?teacher` 주소로 연결해 두었다.

지도안은 첫 화면에 두지 않고 선생님 화면에서만 연결한다. 다만 정적
사이트라 주소를 아는 사람은 그대로 열 수 있다. 접근을 막는 장치가 아니라
학생 눈에 띄지 않게 두는 정리다.
- `firebase-init.js` — 두 화면이 함께 쓰는 Firebase 연결 설정
- `firestore.rules` — 보안 규칙
- `firebase.json` / `.firebaserc` — 규칙 배포 설정
- `vercel.json` — 배포 설정 (`.html` 주소를 그대로 열고, 캐시하지 않음)

## Firebase

Firebase 프로젝트는 **`kim-digital`** 이며 이 수업 전용입니다. 파이썬 첫걸음
채점기와는 별도의 프로젝트라 서로 영향을 주지 않습니다.

선생님 계정은 `teacher@digital.local` 입니다. 로그인 화면에는 아이디 `선생님`만
적으면 됩니다. 이 값을 바꾸려면 `firebase-init.js`의 `TEACHER_EMAIL`과
`firestore.rules`의 `isTeacher()` **두 곳을 함께** 고쳐야 합니다.

보안 규칙을 고쳤다면 이 명령으로 올립니다.

```
firebase deploy --only firestore:rules
```

> 배포된 주소는 Firebase 콘솔의 **Authentication > 설정 > 승인된 도메인**에
> 등록되어 있어야 로그인이 됩니다. 주소가 바뀌면 다시 등록하세요.
>
> 이 저장소는 두 곳에 배포됩니다.
>
> - https://digital-eight-kappa.vercel.app (Vercel)
> - https://kimjuimg.github.io/digital (GitHub Pages)
>
> **두 주소 모두 승인된 도메인에 등록되어 있어야** 로그인이 됩니다.

## 저장되는 것

- `dc_classes/{코드}` — 선생님이 연 수업 코드
- `dc_groups/{모둠}` — 모둠 이름, 두 학생 이름, 미션별 점수, 진행 정도, 약속
- `dc_classroom/{코드}` — 함께 보기에서 선생님이 지정한 미션 이름 하나

학생은 자기 모둠 문서만 쓰고 고칠 수 있습니다. 모둠 순위 전체를 읽는 것은
선생님 계정뿐입니다. 학생은 Firebase에 **익명으로** 들어가며, 이름과 모둠
이름은 계정이 아니라 화면에 적는 값입니다.
